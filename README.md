# Sistema de Planilla Hospitalaria

Proyecto de Programación #2. Es un programa en C++ que se usa desde la consola y sirve para manejar la planilla de un hospital (empleados, departamentos y pagos).

## Cómo usar

Al abrir el programa sale un menú con números. Se escribe el número de la opción y se presiona Enter.

1. Primero hay que crear un departamento y agregarle un puesto.
2. Después se pueden registrar los empleados (médico, enfermero o administrativo).
3. Por último, en la parte de planilla se puede pagar a un empleado o a todos, y se muestra el comprobante con el salario neto.

Los datos se guardan solos en los archivos `empleados.txt`, `departamentos.txt` y `planilla.txt`, y se cargan otra vez cuando se abre el programa.
